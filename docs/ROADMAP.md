# MacOSify Roadmap

## Phase 1 — Core installer
- Detect Ubuntu release and GNOME Shell version
- Detect session type, GPU, RAM, storage and monitors
- Create timestamped restore backup
- Install dependencies safely
- Install WhiteSur GTK, icons, cursors and wallpapers
- Install compatible GNOME extensions
- Apply a conservative macOS-inspired preset

## Phase 2 — Safety
- Dry-run mode
- Safe-mode installer
- Rollback
- Repair
- Uninstall
- Update
- Detailed logs

## Phase 3 — Desktop experience
- Dash to Dock
- Blur / transparency
- Spotlight-like search
- AppIndicator support
- Launchpad-style app grid
- macOS-like shortcuts
- Finder-inspired Nautilus styling
- Firefox integration

## Phase 4 — Compatibility
- GNOME 46–50 compatibility matrix
- Wayland/X11 handling
- HiDPI and fractional scaling checks
- Multi-monitor handling
- Low-end performance profile
- Extension compatibility validation

## Phase 5 — Control Center
- Preset selector
- Light/dark mode
- Accent settings
- Dock settings
- Performance mode
- Backup and rollback controls
