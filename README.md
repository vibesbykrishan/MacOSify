# MacOSify

macOS-inspired desktop transformation for Ubuntu GNOME.

## Goals
- Safe, reversible installation
- GNOME/version and hardware detection
- WhiteSur-based visual foundation
- Dock, blur, icons, cursors and wallpapers
- Performance profiles for low-end hardware
- Backup, rollback, repair, update and uninstall
- No proprietary Apple binaries or copyrighted Apple assets bundled

## Development
This repository is being built as a test-first project before public release.

## Planned installer
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/vibesbykrishan/MacOSify/main/macosify.sh)
```

The URL becomes valid only after the repository is published and the installer is tested.
